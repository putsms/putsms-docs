---
title: Getting Started
description: Create an account, connect a device, and receive your first message.
---

This guide uses the hosted Dashboard. Self-hosted users should [deploy the stack](/docs/self-hosting/deployment) first and substitute their own Dashboard and API origins.

<Steps>

### Create an account

Open the Dashboard and register with email and password or the configured Google sign-in. Sign in before creating devices.

### Add a device

Open **Devices**, choose **Add device**, enter a recognizable name, and select the platform. Creation saves only the device record, then opens **Connect**. The platform is descriptive and can be changed later without changing the connection.

### Choose a connection method

Choose **API Key** for a Bearer authorization header, **Put URL** when the key must be embedded in the upload URL, or **SMS registration** for an app or device that can redeem a short-lived code. API Key and Put URL create the same long-lived Device Key and differ only in how Dashboard presents it. The key is shown once and does not expire automatically.

<Callout type="warn" title="Save the credentials now">
  Treat the Device Key or complete Put URL like a password. Do not place it in source control, screenshots, chat, or logs. Generate a replacement or disconnect the device if it is exposed.
</Callout>

### Configure a message source

Choose the matching guide:

- [iOS App and Shortcuts](/docs/guides/ios)
- [Android SmsForwarder](/docs/guides/android)
- [Air780EPM](/docs/guides/air780epm)

For common setups, use Put URL with iOS Shortcuts or Android SmsForwarder, API Key with an app or browser extension that supports Bearer headers, and SMS registration with the iOS app or Air780EPM firmware when supported.

### Confirm the connection

Return to **Devices** and check **Status**. `Not connected` means no active credential, `Ready` means a Key or registration code exists but has not been used, and `Connected` means the Key completed a successful request or the SMS code was redeemed. Select the status at any time to reopen **Connect**.

### Send a test message

Trigger the configured Shortcut, forward an Android SMS, or send an SMS to the Air780EPM SIM. Open **Messages** in the Dashboard and confirm sender, content, receive time, and source device.

### Add reading clients

Configure the [browser extension](/docs/guides/browser-extension) for persistent notifications, or bind another iOS device for synchronized access.

</Steps>

For sensitive messages, continue with [End-to-end encryption](/docs/guides/encryption) before enabling required encrypted uploads.
