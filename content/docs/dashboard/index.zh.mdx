Dashboard 是部署到 Cloudflare Pages 的 React Router 静态应用，通过 `VITE_API_BASE_URL` 直接访问 Worker。

## 本地开发

先启动 `putsms-api`，再运行：

```sh
cd putsms-dash
pnpm install
VITE_API_BASE_URL=http://localhost:8787 pnpm dev
```

打开 `http://localhost:5173`。Vite 不代理 `/api`；从其他设备访问时，API 地址也必须能被该设备访问。

## 命令

- `pnpm dev`：启动开发服务器。
- `pnpm typecheck`：生成 React Router 类型并检查 TypeScript。
- `pnpm test`：运行前端测试。
- `pnpm build`：构建到 `build/client`。
- `pnpm preview`：本地预览生产构建。
- `pnpm deploy`：部署到 Cloudflare Pages。

API 请求、SSE、Google OAuth 起始地址和生成的连接地址都使用同一个 `VITE_API_BASE_URL`。

## 设备连接

创建设备只保存名称和描述性平台，随后打开 Connect 窗口。Status 列是唯一的连接管理入口；所有平台均可使用 API Key、Put URL 或 SMS registration。

API Key 与 Put URL 生成同一种长期 Device Key，Dashboard 根据所选方式显示 Bearer Header 或带 Key 的 URL。生成 Key 后状态为 `Ready`，首次成功鉴权请求后才变成 `Connected`。SMS registration 生成十分钟有效、仅可使用一次的注册码，兑换后立即连接。**Disconnect** 会撤销两种凭据并重置连接状态，但不会删除设备及其数据。
