Dashboard 是部署到 Cloudflare Pages 的 React Router 静态应用，通过 `VITE_API_BASE_URL` 直接访问 Worker。

## 本地开发

先启动 `putsms-api`，再运行：

```sh
cd putsms-dash
pnpm install
VITE_API_BASE_URL=http://localhost:8787 pnpm dev
```

打开 `http://localhost:5173`。Vite 不代理 `/api`；从其他设备访问时，API 地址也必须能被该设备访问。

## 命令

- `pnpm dev`：启动开发服务器。
- `pnpm typecheck`：生成 React Router 类型并检查 TypeScript。
- `pnpm test`：运行前端测试。
- `pnpm build`：构建到 `build/client`。
- `pnpm preview`：本地预览生产构建。
- `pnpm deploy`：部署到 Cloudflare Pages。

API 请求、SSE、Google OAuth 起始地址和设备配置二维码都使用同一个 `VITE_API_BASE_URL`。

## Embedded 短信注册

Embedded 设备使用短信注册，不会在创建弹窗中暴露 Device Key。Dashboard 会生成一次性注册码，显示 `PUTSMS REG` 命令和有效期倒计时，允许填写自定义 HTTPS API 地址，并在模组兑换注册码后检查连接状态。

已连接的 Embedded 设备可在注册状态菜单中解绑。解绑会立即撤销当前 Token，并将记录恢复为等待配置，以便连接新账号或重新配置。Embedded 设备不能与其他平台相互转换，其凭据也不使用普通轮换界面。
