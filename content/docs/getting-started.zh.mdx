---
title: 快速开始
description: 创建账号、连接设备并接收第一条短信。
---

本指南使用托管版 Dashboard。自部署用户应先[部署完整服务](/zh/docs/self-hosting/deployment)，并将文中的 Dashboard 和 API 地址替换为自己的域名。

<Steps>

### 创建账号

打开 Dashboard，通过邮箱和密码注册，或使用已配置的 Google 登录。登录后才能创建设备。

### 添加设备

进入 **Devices**，选择 **Add device**，填写容易识别的名称并选择平台。创建操作只保存设备记录，随后自动打开 **Connect**。平台只是设备描述，之后可以修改，不会改变连接方式。

### 选择连接方式

需要 Bearer 请求头时选择 **API Key**；无法设置请求头、需要把 Key 放入上传地址时选择 **Put URL**；App 或设备能够兑换短期注册码时选择 **SMS registration**。API Key 与 Put URL 生成的是同一种长期 Device Key，只是 Dashboard 的展示方式不同。Key 仅显示一次，且不会自动过期。

<Callout type="warn" title="立即保存凭据">
  请像密码一样保护 Device Key 或完整 Put URL，不要放入源码、截图、聊天或日志。发生泄露时应生成替代 Key，或断开设备。
</Callout>

### 配置短信来源

选择对应指南：

- [iOS App 与快捷指令](/zh/docs/guides/ios)
- [Android SmsForwarder](/zh/docs/guides/android)
- [Air780EPM](/zh/docs/guides/air780epm)

常见选择是：iOS 快捷指令与 Android SmsForwarder 使用 Put URL；支持 Bearer Header 的 App 或浏览器扩展使用 API Key；支持自动兑换的 iOS App 或 Air780EPM 固件使用 SMS registration。

### 确认连接

返回 **Devices** 检查 **Status**。`Not connected` 表示没有有效凭据，`Ready` 表示已经生成 Key 或注册码但尚未使用，`Connected` 表示 Key 已成功请求 API，或 SMS 注册码已经兑换。随时点击状态都可以重新打开 **Connect**。

### 发送测试短信

运行已配置的快捷指令、转发一条 Android 短信，或向 Air780EPM 的 SIM 卡发送短信。打开 Dashboard 的 **Messages**，核对发送方、正文、接收时间和来源设备。

### 添加阅读端

配置[浏览器扩展](/zh/docs/guides/browser-extension)以持续接收通知，或绑定另一台 iOS 设备进行同步访问。

</Steps>

如果短信包含敏感内容，请在开启强制加密上传前继续阅读[端到端加密](/zh/docs/guides/encryption)。
