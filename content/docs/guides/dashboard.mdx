---
title: Use the Dashboard
description: Manage devices, messages, contacts, and account security.
---

<Steps>

### Sign in

Register with email and password, or use Google sign-in when your deployment enables it.

### Create a device

Open **Devices**, select **Add device**, choose its platform, and give it a recognizable name. Save the one-time Device Key or scan the configuration QR code immediately for regular clients. Embedded devices use **Generate SMS code** instead: send the displayed command to the modem SIM before the ten-minute code expires.

### Work with messages

Use **Messages** to browse or search by sender and content. Mark messages read or unread, delete records you no longer need, and use contacts to give frequent senders meaningful names.

### Maintain access

Review connected devices and public keys regularly. Rotate a regular Device Key after accidental disclosure; update the source before revoking the old credential. Embedded credentials cannot be rotated from the regular flow. Use **Unbind device**, then generate and send a new SMS enrollment command; the old token stops working immediately.

</Steps>

<Callout type="warn" title="Device Keys are credentials">Anyone with a Device Key can act as that source device. Do not paste it into tickets, chat, screenshots, logs, or source control.</Callout>
