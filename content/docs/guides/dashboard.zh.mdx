---
title: 使用 Dashboard
description: 管理设备、短信、联系人和账号安全。
---

<Steps>

### 登录

使用邮箱和密码注册；如果部署方启用了 Google 登录，也可直接使用 Google 账号。

### 创建设备

打开 **Devices**，选择 **Add device**，选择平台并填写容易识别的名称。Dashboard 保存记录后会立即打开 **Connect**。选择 API Key、Put URL 或 SMS registration；所有平台都支持这三种方式，平台仅用于描述设备并可在之后修改。

Status 列是唯一的连接管理入口。`Not connected` 表示没有有效凭据，`Ready` 表示等待 Key 首次使用或注册码兑换，`Connected` 表示已经完成首次使用。点击任意状态都可以重新打开 Connect。

### 处理短信

在**短信**中浏览，或按发送方和内容搜索。你可以标记已读/未读、删除不需要的记录，并用联系人为常见号码设置名称。

### 维护访问权限

定期检查已连接设备和公钥。Device Key 不会自动过期；发生泄露时应生成替代 Key，或使用 **Disconnect** 撤销 Key 和未使用的注册码。Disconnect 会重置连接与同步时间，但保留设备、短信、备注和加密密钥绑定。

</Steps>

<Callout type="warn" title="Device Key 是访问凭据">持有 Device Key 的人可以模拟该来源设备。不要将它放入工单、聊天、截图、日志或版本库。</Callout>
