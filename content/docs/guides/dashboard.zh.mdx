---
title: 使用 Dashboard
description: 管理设备、短信、联系人和账号安全。
---

<Steps>

### 登录

使用邮箱和密码注册；如果部署方启用了 Google 登录，也可直接使用 Google 账号。

### 创建设备

打开**设备**，选择**添加设备**，选择平台并填写容易识别的名称。普通客户端应立即保存一次性展示的 Device Key，或扫描配置二维码。Embedded 设备改用**生成短信注册码**，并在十分钟有效期内将显示的命令发送到模组 SIM 卡。

### 处理短信

在**短信**中浏览，或按发送方和内容搜索。你可以标记已读/未读、删除不需要的记录，并用联系人为常见号码设置名称。

### 维护访问权限

定期检查已连接设备和公钥。普通 Device Key 意外泄露后应轮换凭据；撤销旧凭据前，先更新对应来源设备。Embedded 凭据不能走普通轮换流程，应先**解绑设备**，再生成并发送新的短信注册命令；旧 Token 会立即失效。

</Steps>

<Callout type="warn" title="Device Key 是访问凭据">持有 Device Key 的人可以模拟该来源设备。不要将它放入工单、聊天、截图、日志或版本库。</Callout>
