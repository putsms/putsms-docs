---
title: Android SmsForwarder
description: Forward Android SMS to a PutSMS device URL.
---

Create an Android device in Dashboard. In the Connect dialog choose **Put URL**, generate the credential, and copy the URL shown once:

```text
https://<worker-domain>/put/<deviceKey>
```

Configure SmsForwarder to POST JSON or form fields. `sender` and `content` are required; `receiver`, `receivedAt`, `simSlot`, and `clientVersion` are optional.

```json
{
  "sender": "[from]",
  "receiver": "[receiver number]",
  "content": "[msg]",
  "receivedAt": "[receive_time]",
  "simSlot": "[card_slot]"
}
```

After generation the device is `Ready`. Send a test SMS and verify that it becomes `Connected` in Dashboard. A `401` response usually means the key was copied incorrectly, replaced, or revoked by Disconnect.

<Callout type="warn" title="Transport encryption only">This integration currently sends plaintext JSON over HTTPS. It does not produce PutSMS E2EE ciphertext. Use HTTPS and protect the Put URL as a password.</Callout>
