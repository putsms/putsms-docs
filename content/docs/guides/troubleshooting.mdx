---
title: Troubleshooting
description: Diagnose configuration, synchronization, notification, and encryption problems.
---

| Symptom | Check |
| --- | --- |
| Device stays `Ready` | The generated Key has not completed a successful authenticated request, or the SMS registration code has not been redeemed |
| Device is `Not connected` | Open Status, choose a connection method, and generate a Key or registration code |
| `401` or `403` | Key copied in full, not revoked, and belongs to the selected API origin |
| Messages do not sync | Network, pending local records, system background permissions, and API logs |
| Dashboard or extension does not update live | SSE request to `/api/v1/events`, CORS origin, connection status, and reconnect state |
| Browser extension has no desktop notification | **Test notification**, browser/OS notification permission, and Focus/Do Not Disturb |
| Verification-code prompt does not appear | Prompt toggle, excluded host rules, a contextual 4-8 digit code, and local decryption for encrypted messages |
| **Fill code** does not fill | Focus a supported text/tel/number input; cross-origin frames, segmented fields, and closed Shadow DOM are unsupported |
| No iOS notification | Notification permission, APNs registration, queue consumer, APNs environment/topic |
| Encrypted message is unreadable | Matching local private key and recovery backup for that message |
| Required encrypted upload fails | At least one active compatible reader public key must be registered |
| Air780EPM does not connect | Cellular/SNTP readiness, the enrollment reply or direct-upload credential, `/putsms_device.json`, and HTTPS API origin |
| Key returns `401` after Disconnect | Disconnect revoked it; open Status and generate a new credential |
| SMS registration code fails | The code is unused, within its ten-minute lifetime, and the client supports automatic redemption |
| Air780EPM old Key returns `401` | The device was disconnected or its Key was replaced; open Connect and configure a new Key or SMS registration code |
| Imported iOS key is pending | The selected backup matches a visible source device and the API is reachable |

Rotate exposed Device Keys rather than retrying them. Do not post message bodies, Put URLs, private keys, or complete request headers in support logs.

For self-hosted systems, also inspect Worker logs, Queue failures, D1 migration state, and the [deployment checklist](/docs/self-hosting/deployment).
